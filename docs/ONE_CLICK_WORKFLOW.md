# One-click workflow stages

```text
CONCEPT
  Validate the idea, cast, authorization, runtime, and explicit provider ceilings.

FREE PREPRODUCTION
  Generate or ingest the screenplay, run TGRM, build the complete shot deck,
  audit screenplay and prompts, and hash the prompt ledger without provider calls.

PRODUCTION MEMORY
  Load prior project facts, characters, locations, props, preferences, model
  outcomes, accepted-shot evidence, and repair scars. Rebuild the final contract.

ROUTING
  Recommend a model for every shot and retain a safe execution model and fallback.

GENERATION
  Start the durable queue, persist provider prediction IDs, verify media, and
  preserve accepted clips after every unit of work.

QUALITY
  Apply local visual QA and optional authorized semantic shot-contract review.

FINISHING
  Rebuild adaptive cinematic transitions, optionally generate voices and captions,
  and write project quality evidence plus a machine-readable edit-decision list.

CONTINUE
  If provider, budget, or hosting limits interrupt the request, continue the same
  autonomous job without discarding accepted work or project memory.
```
